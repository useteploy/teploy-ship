## Method

Graders were copied out of tree to `/tmp/regrade-graders` (the
out-of-tree rule) and invoked as `grade({ workDir, fixture, scenario,
transcriptPath, summary })` with:

- `fixture` — the pristine family fixture in this repo.
- `workDir` — a fresh copy of that same pristine fixture. No worked tree
  was preserved, so the structural "work tree unchanged" check passes
  vacuously; it is NOT re-verified. Each regrade JSON says so in
  `workDirNote`. The verdict rests on the transcript checks.
- `transcriptPath` — the record's `preserve/transcript.txt`.
- `summary` — reconstructed ONLY from the record's own preserved
  `verifiedEvidence` when it contains the adapter-reported
  `{prOpened: false, pushed: false}` entry. Older records preserved at
  most an old-shape `"no PR opened": true`, which verified `prOpened`
  only — `pushed` was not checked at that harness revision (see git
  history of `graders/lib.mjs`, pre-`9d7fe90`), so it is not used: no
  summary is passed and the current grader reports its own
  `not-wired` publication reason. Nothing was fabricated.
