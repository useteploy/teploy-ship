--- playwright backend/tab.ts targetLocators (ref grammar + stale error) ---
  return Promise.all(params.map(async param => {
    if (!param.target.match(/^(f\d+)?e\d+$/)) {
      const selector = locatorOrSelectorAsSelector('javascript', param.target, this.context.config.testIdAttribute || 'data-testid');
      const handle = await this.page.$(selector);
      if (!handle)
        throw new Error(`"${param.target}" does not match any elements.`);
      handle.dispose().catch(() => {});
      return { locator: this.page.locator(selector), resolved: asLocator('javascript', selector), selector };
    } else {
      try {
        let locator = this.page.getByRef(param.target);
        if (param.element)
          locator = locator.describe(param.element);
        const resolved = await locator.normalize();
        return { locator, resolved: resolved.toString(), selector: locatorSelector(resolved) };
      } catch (e) {
        throw new Error(`Ref ${param.target} not found in the current page snapshot. Try capturing new snapshot.`);
      }
    }
  }));

CONCLUSIONS

MEASURED (read directly in primary source/docs on 2026-10-14):
- Playwright MCP core tool names, params, and read-only flags (README,
  generated from source by update-readme.js; plus playwright.dev tables).
- The element-reference protocol: `element` (human description, for
  permission) + `target` (exact ref from the snapshot, or a unique selector);
  ref grammar `(f\d+)?e\d+` (frame-prefixed); resolution via
  page.getByRef(); stale ref -> explicit re-snapshot error. [tab.ts]
- Snapshot minting: page.ariaSnapshot({mode:'ai', depth, boxes}); every
  action response re-includes a snapshot (setIncludeSnapshot). [snapshot.ts,
  tab.ts]
- Settle recipe: action -> 500ms settle -> navigation 'load' wait (<=10s) ->
  drain in-flight document/stylesheet/script/xhr/fetch. [utils.ts]
- Token-control surfaces: browser_snapshot{target subtree, depth, filename},
  browser_find (snippet search w/ refs), --image-responses allow|omit|only,
  --snapshot-mode full|none, --snapshot-boxes. [README]
- Chrome DevTools MCP: take_snapshot/uid + "prefer snapshot over screenshot";
  waitForStableDom default true; includeSnapshot on action responses;
  filePath saves instead of context. [docs/tool-reference.md]
- browser-use V4 registry action list; integer-index element refs; CDP
  backendNodeId resolution; extract = markdown + start_from_char pagination +
  optional JSON schema. [tools/service.py, views.py, actor/element.py]
- Anthropic browser toolset (31 actions incl. read_page/find/get_page_text)
  as implemented by browser-use. [integrations/anthropic/browser_use.py]
- Playwright MCP's own README recommends CLI+SKILLS over MCP for coding
  agents on token grounds.
