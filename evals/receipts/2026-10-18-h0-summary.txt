Cross-cutting observations:
- All four ACP agents answered protocolVersion 1 to a client offering 2.
  T3's pinned schema generation is 2 (PROTOCOL_VERSION = 2); real agents at
  these pins negotiate down. ship-acp must accept 1 in the initialize
  result and record it in preflight.
- initialize needed no credentials on every agent probed (incl. the binary
  cursor distribution). Auth is a post-initialize concern (authenticate /
  auth_required), matching T3's runtime.
- No agent advertised resume-capable sessionCapabilities AND an env-key
  method at the same time: cursor has list-only; grok has list+resume+close
  but only the subscription method advertised; qwen has list+resume.
  Steering (H5) keys off loadSession:true, which all four ACP agents set.
- The ACP registry (v1.0.0, 42 agents, cdn.agentclientprotocol.com,
  fetched 2026-10-18) already pins gemini, grok-build, cursor and qwen-code;
  its cursor binary entry has no sha256 (H9's mandatory-sha256 rule for
  binaries is stricter than the registry, and this is the concrete case).

2. D6 ADAPTER COST (recorded; opens the D8 gate)
================================================================================
D6 = the opencode v2 adapter, the most recent bespoke adapter. Source: git
history of src/harness-external.ts around PR #101 in this repo.

- Measured contract first: evals/receipts/2026-10-14-opencode-v2-events.txt
  (PROOF C, event contract of opencode 2.0.26 vs 1.x, recorded 2026-10-14).
- Adapter landed: commit 0d67082 "feat(harness): OpenCode v2 adapter +
  session-resume steering for opencode and claude-code (D6/D7)", merged as
  PR #101 (627a370) on 2026-10-16 — receipt-to-merge gap of two days.
- Commit size: 19 files, +1151 / -279 total. The adapter core,
  src/harness-external.ts: +437 / -91. The largest other hunks are the
  parser tests (src/harness-external.test.ts ~447 changed lines) and
  capability/conformance updates (harness-capabilities.ts 69,
  harness-probes.ts 40).
- Parser today: parseOpencode2Stream is 63 lines of code plus a 21-line
  measured-contract comment (src/harness-external.ts:649-732); the whole
  bespoke-adapter file is 1479 lines for three vendors (claude, opencode
  1+2, codex) — consistent with the design note's "about 1,400 lines".
- What that cost bought per vendor: invocation selection, preflight,
  JSONL event parser, live tracker, usage/pricing honesty, steering
  resume, and the replay pin. The ACP thesis (D8) is that initialize +
  session/update + request_permission replace the per-vendor parser and
  permission guesswork for the new agents, at the price of one driver.
- Codex comparison from the same file: commit efdd56c (codex exec --json
  adapter, PR #100) — the codex parser is similarly sized; both adapters
  needed a receipt before code, which is the process cost ACP profiles
  would not pay per agent (only the generic conformance suite, once).
